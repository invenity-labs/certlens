# CertLens site

The public pages for the CertLens browser extension: landing, [privacy policy](https://invenity-labs.github.io/certlens/privacy/) and [support](https://invenity-labs.github.io/certlens/support/), served by GitHub Pages at https://invenity-labs.github.io/certlens/.

Static HTML, no scripts, no analytics. Generated from the extension's own documentation; edits are made there and published here.

Problems with the extension: [open an issue](https://github.com/invenity-labs/certlens/issues).
